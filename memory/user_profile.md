Technical background: comfortable with Python, PyPSA, CoolProp, thermodynamics, and LP optimisation. Uses Gurobi as primary solver.

Working style: prefers to discuss concepts and plan before implementing; likes to implement in phases and test between them. Does not want rushed or overly verbose responses.
